# STRM 源链接检查插件

## 概述

**STRM 源链接检查** 是一个用于 MoviePilot 的插件，用于监控 STRM 文件中的源链接有效性。当检测到源链接失效时，可通过 Emby API 自动删除已入库 Emby 中对应的条目及附属文件。

## 功能特性

- 扫描指定目录下的所有 `.strm` 文件
- 通过 HTTP HEAD/GET 请求检查 STRM 文件中的源链接是否有效
- 支持定时自动检查（cron 表达式配置）
- 支持手动触发检查（通过插件命令 `/strm_check` 或 API）
- 源链接失效时，自动通过 Emby API 删除对应的单个条目（不会删除整个视频项目）
- 可选删除失效的 STRM 文件
- 可选删除附属文件（同名的 `.jpg` / `.nfo` 文件）
- 可选删除整理记录
- 自动递归删除空父目录
- 保留最近 500 条检查记录，可在插件详情页查看

## 配置说明

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启/关闭插件 |
| 发送通知 | 检查完成后是否发送通知消息 |
| 删除失效 STRM | 源链接失效时，自动删除对应的 STRM 文件 |
| 删除附属文件(jpg/nfo) | 源链接失效时，自动删除同名的 `.jpg` 和 `.nfo` 文件 |
| 删除整理记录 | 源链接失效时，自动删除 MoviePilot 中的整理记录 |
| 执行周期(cron) | 5 位 cron 表达式，例如 `0 6 * * *` 表示每天早上 6 点执行 |
| 请求超时(秒) | HTTP 请求超时时间，默认 10 秒 |
| STRM 文件目录路径 | STRM 文件所在的目录路径，支持多行（每行一个目录） |
| Emby 地址 | Emby 服务器地址，留空则使用系统配置的媒体服务器 |
| Emby API Key | Emby API 密钥，留空则使用系统配置的媒体服务器 |

## 使用方法

### 1. 安装插件

在 MoviePilot 插件市场中搜索 "STRM源链接检查" 并安装。

### 2. 配置插件

进入插件配置页面，填写以下信息：
- **STRM 文件目录路径**：填写你的 STRM 文件存放目录
- **执行周期**：建议设置为每天执行一次，如 `0 6 * * *`
- 根据需要开启删除选项

### 3. 手动运行

配置完成后，勾选 **"立即运行一次"** 并保存，插件会立即执行一次检查。

### 4. 通过命令触发

在支持命令输入的渠道发送 `/strm_check` 即可手动触发检查。

### 5. 通过 API 触发

```
GET /api/v1/plugin/StrmLinkChecker/run_check?apikey=YOUR_API_KEY
```

## 工作流程

1. 扫描配置目录下的所有 `.strm` 文件
2. 读取每个 STRM 文件中的源链接
3. 通过 HTTP HEAD 请求检查源链接是否有效
4. 如果 HEAD 请求返回 4xx，尝试 GET 请求（带 Range 头）再次验证
5. 如果源链接有效，记录状态并跳过
6. 如果源链接失效：
   - 通过转移记录查找对应的媒体信息
   - 通过 Emby API 精确匹配路径并删除该条目
   - 根据配置决定是否删除 STRM 文件、附属文件、整理记录
7. 发送通知（如已开启）

## 注意事项

- 删除 Emby 媒体库条目操作不可逆，请谨慎使用
- 建议先手动运行一次检查结果，确认无误后再开启定时任务
- 插件只删除精确匹配该 STRM 路径的 Emby 条目，不会删除整个视频项目
- 如果 Emby 地址和 API Key 留空，将自动使用系统配置的媒体服务器
