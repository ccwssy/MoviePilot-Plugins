# Strm失效清理

## 概述

**Strm失效清理** 是一个用于 MoviePilot 的插件，通过转移记录对比 Emby 媒体库中的 STRM 文件与源 STRM 文件，如果源文件已删除，则自动通过 Emby API 删除对应的条目及附属文件。

## 功能特性

- 扫描指定目录下的所有 `.strm` 文件
- 通过转移记录（transfer_history）查找每个 STRM 文件的源文件路径
- 检查磁盘上源 STRM 文件是否存在
- **重复入库清理**：同一源文件（src）对应多个入库文件（dest）时，只保留最新转移记录对应的文件，删除其他重复文件及 Emby 条目（通过精确 src 路径匹配，不同版本如 DV/HDR 不会被误删）
- 源文件缺失时，自动通过 Emby API 删除对应的单个条目（不会删除整个视频项目）
- 可选删除失效的 STRM 文件
- 可选删除附属文件（同名的 `.jpg` / `.nfo` 文件）
- 可选删除整理记录
- 自动递归删除空父目录
- 支持对无转移记录的 STRM 文件进行 URL 可用性检查（风险功能，需手动启用）
- URL 缓存有效期配置：可设定天数，超过有效期后自动重新检查 URL 可用性
- 保留最近 500 条检查记录，可在插件详情页查看（按状态分类展示：重复入库清理、无转移记录、源文件缺失、检查失败、有效）

## 配置说明

### 基础设置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启/关闭插件 |
| 立即运行一次 | 勾选并保存后立即执行一次检查 |
| 发送通知 | 检查完成后是否发送通知消息 |
| 执行周期 | 5 位 cron 表达式，例如 `0 6 * * *` 表示每天早上 6 点执行。留空则仅手动触发 |
| STRM目录路径 | MP2 容器内入库后的 STRM 文件目录，支持多行（每行一个目录） |

### 清理操作

| 配置项 | 说明 |
|--------|------|
| 删除失效 STRM | 源文件缺失时，自动删除对应的 STRM 文件 |
| 删除附属文件(jpg/nfo) | 源文件缺失时，自动删除同名的 `.jpg` 和 `.nfo` 文件 |
| 删除整理记录 | 源文件缺失时，自动删除 MoviePilot 中的整理记录 |

### Emby 连接

| 配置项 | 说明 |
|--------|------|
| Emby 地址 | Emby 服务器地址，留空则使用系统配置的媒体服务器 |
| Emby API Key | Emby API 密钥，留空则使用系统配置的媒体服务器 |

### URL可用性检查（风险功能）

| 配置项 | 说明 |
|--------|------|
| 启用 URL 可用性检查 | 开启后对无转移记录的 STRM 文件进行 HTTP 请求测试 |
| 线程数 | 并发检查线程数（1-3） |
| 请求间隔 | 每次请求后的等待时间（3-60秒），用于降低风控风险 |
| 每日上限 | 每天最多检查次数（10-500） |
| 缓存有效期 | URL 检查结果缓存的天数，超过有效期后自动重新检查。设为 0 表示无限期（仅当 STRM 文件 mtime 变化时才重新检查） |

## 使用方法

### 1. 安装插件

在 MoviePilot 插件市场中搜索 "Strm失效清理" 并安装。

### 2. 配置插件

进入插件配置页面，填写以下信息：
- **STRM目录路径**：填写 MP2 容器内入库后的 STRM 文件目录
- **执行周期**：建议设置为每天执行一次，如 `0 6 * * *`
- 根据需要开启清理选项

### 3. 手动运行

配置完成后，勾选 **"立即运行一次"** 并保存，插件会立即执行一次检查。

### 4. 通过命令触发

在支持命令输入的渠道发送 `/strm_check` 即可手动触发检查。

### 5. 通过 API 触发

```
GET /api/v1/plugin/StrmLinkChecker/run_check?apikey=YOUR_API_KEY
```

## 工作流程

1. 扫描配置的 STRM 目录下的所有 `.strm` 文件
2. 通过转移记录（transfer_history）查找每个 STRM 文件的源文件路径（src）
3. 检查磁盘上源 STRM 文件是否存在
4. 源文件存在 → 记录为"有效"，跳过
5. 源文件不存在 → 执行清理：
   - 通过 Emby API 精确匹配路径并删除条目
   - 可选删除 STRM 文件本身
   - 可选删除同名的 `.jpg` / `.nfo` 附属文件
   - 可选删除整理记录
   - 自动递归删除空父目录
6. 发送通知（如已开启）

## 注意事项

- 删除 Emby 媒体库条目操作不可逆，请谨慎使用
- 建议先手动运行一次检查结果，确认无误后再开启定时任务
- 插件只删除精确匹配该 STRM 路径的 Emby 条目，不会删除整个视频项目
- 如果 Emby 地址和 API Key 留空，将自动使用系统配置的媒体服务器
- URL可用性检查可能触发网盘或文件服务器的风控机制，请谨慎使用
