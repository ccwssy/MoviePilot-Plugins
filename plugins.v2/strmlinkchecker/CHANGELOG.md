# 更新日志

## v1.1 (2026-05-30)

### 修复
- 不再依赖源STRM目录与Emby媒体库目录结构一致
- 改为通过转移记录（transfer_history）的 `src` 字段查找源STRM文件路径
- 直接检查磁盘上源文件是否存在，不再需要配置源STRM目录路径

### 变更
- 移除配置项 `源STRM文件目录路径`（`source_strm_path`）
- 插件描述更新为更准确的说明

## v1.0 (2026-05-30)

### 初始版本
- 初始发布，基于 `2.0.0` 重构版本号体系
- 扫描Emby媒体库STRM文件，通过转移记录查找源文件
- 源文件缺失时自动删除Emby条目、STRM复制体及附属文件
