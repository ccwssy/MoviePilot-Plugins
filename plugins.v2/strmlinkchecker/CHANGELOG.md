# 更新日志

## v1.1.0 (2026-05-31)

### 新增
- 远程可达性验证（风险功能）：当STRM文件无转移记录时，读取文件内URL并发送HEAD请求验证源是否可达
- 新增配置项：线程数、请求间隔冷却时间、单次最大验证数、低峰时段开关
- 新增详情页状态分类：「🌐 远程有效」和「📡 远程不可达」
- 通知统计增加远程验证结果行
- 验证请求使用 HEAD + 降级 GET（兼容不支持HEAD的CDN）
- 线程锁控制冷却时间，避免触发源站风控

### 变更
- 插件版本升级至 1.1.0

## v1.0.1 (2026-05-30)

### 变更
- 移除配置项 `源STRM文件目录路径`（`source_strm_path`）
