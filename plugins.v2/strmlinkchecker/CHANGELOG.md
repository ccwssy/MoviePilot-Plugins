# 更新日志

## v1.0.8 (2026-05-31)

### 新增
- URL可用性检查（风险功能）：对于没有转移记录的STRM文件，通过HTTP HEAD/GET请求测试源URL是否可访问
- 新增独立配置UI：启用开关、线程数、冷却时间、每日检查上限
- URL检查缓存机制：已检查文件记录mtime，下次无变化时跳过，避免重复请求

### 风控
- 线程数限制(1-3)、请求间冷却(3-60秒)、每日上限(10-500次)
- 随机打乱扫描顺序，降低规律性特征
- 使用Range: bytes=0-0最小化数据传输
