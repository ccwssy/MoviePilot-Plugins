# 更新日志

## v1.4.0 (2026-07-10)

### 重构
- 整合文件同步与番号刮削为统一插件
- 文件同步和番号刮削共用目录映射配置
- 两模式同时启用时，匹配番号正则的视频走刮削，其他文件走同步
- 刮削模式支持复制/软链接两种整理方式
- 刮削模式保持源目录结构，自动改名为番号.后缀
- 父目录已包含番号时不重复创建子目录
- 刮削模式写入完整 NFO 元数据和海报
- 去掉独立的分类方式（按演员/制作商/类型），统一保持源目录结构
- 界面全面重排为三个卡片布局
- 默认 MetaTube 地址改为 8897 端口
