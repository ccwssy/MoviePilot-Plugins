# MetaTube 刮削器

## 简介

整合文件同步与番号刮削。监控源目录文件变化，按目录结构不变同步文件，或识别番号视频自动整理入库并写入 NFO 文件及海报。

## 功能特性

### 文件同步模式
- 监控源目录，按目录结构不变复制或创建软链接到目的目录
- 支持多对目录映射
- 源文件删除时同步清理目的文件及附属文件

### 番号刮削模式
- 监控源目录，用 MetaTube API 识别番号视频
- 自动整理到 `目的目录/电影/分类/番号.后缀`
- 支持按演员、制作商、类型或不分类四种分类方式
- 写入完整 NFO 元数据（标题、番号、简介、演员、制作商、评分等）
- 下载海报和背景图
- 自动改名为番号文件名

### 混合模式
- 两模式可同时启用
- 匹配番号正则的视频文件走刮削整理
- 不匹配的其他文件走文件同步

## 配置说明

### 基础设置
| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启后启动实时监控 |
| 立即全量扫描 | 首次部署时勾选，遍历所有目录执行一次全量处理 |
| 发送通知 | 操作完成后发送通知 |

### 文件同步模式
| 配置项 | 说明 |
|--------|------|
| 文件同步模式 | 开启文件同步功能 |
| 同步方式 | 复制文件 / 创建软链接 |
| 目录映射 | 每行一对，格式 `源目录:目的目录`，支持子路径 |
| 同步文件后缀 | 逗号分隔，仅处理这些后缀的文件 |
| 删除附属文件 | 源文件删除时一并清理同名的附属文件 |
| 附属文件后缀 | 逗号分隔 |

### 番号刮削模式
| 配置项 | 说明 |
|--------|------|
| 番号刮削模式 | 开启番号刮削功能 |
| 整理方式 | 复制文件 / 创建软链接 |
| 分类方式 | 按演员 / 按制作商 / 按类型 / 不分类 |
| 海报类型 | 主海报 / 缩略图 |
| MetaTube 地址 | MetaTube 服务器地址 |
| Token | MetaTube API Token（可选） |
| 番号正则 | 文件名匹配该正则才触发 MetaTube 识别 |
| 下载海报 | 是否下载海报和背景图 |
| 跳过已有 | 已有 NFO 文件时跳过 |

## 使用示例

```
目录映射：
/media/downloads/jav:/media/library/jav

同步文件后缀：
.strm, .mkv, .mp4, .avi, .ts, .iso

番号正则：
^[A-Za-z]{1,6}-\d{2,}(?:-[A-Z0-9]+)?$
```

源目录 `/media/downloads/jav` 下有：
- `ABC-123.mp4` → 匹配番号正则 → 刮削到 `/media/library/jav/电影/演员名/ABC-123/ABC-123.mp4` + NFO + 海报
- `movie.mkv` → 不匹配番号正则 → 同步到 `/media/library/jav/movie.mkv`

## 触发方式

- **实时监控**：启用插件后自动启动
- **立即全量扫描**：配置页开关
- **命令**：`/metatube_scrape_all`
- **API**：`GET /api/v1/plugin/MetaTubeScraper/scan?apikey=xxx`
