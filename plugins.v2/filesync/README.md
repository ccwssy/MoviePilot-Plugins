# 文件同步

## 简介

监控源目录文件变化，按目录结构不变同步复制或创建软链接到目的目录，支持附属文件清理。

## 功能特性

- **两种同步模式**：复制文件 或 创建软链接，二选一
- **多目录映射**：支持多对源目录→目的目录，每行一对
- **子路径保持**：源目录下的子目录结构在目的目录中完全镜像
- **实时监控**：基于 watchdog 监控文件创建/修改/删除/移动，增量同步
- **全量初始化**：首次部署支持立即全量同步
- **源文件删除同步清理**：源文件删除时自动删除目的目录中对应的文件
- **附属文件清理**：可选删除同名的附属文件（封面、元数据、字幕等）
- **自定义文件后缀**：可配置需要同步的文件后缀
- **通知**：全量同步完成后可选发送通知
- **同步记录**：保存一对一映射记录，可在详情页查看

## 配置说明

### 基础设置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启后启动实时监控 |
| 立即全量同步 | 首次部署时勾选，保存后执行一次全量同步 |
| 发送通知 | 全量同步完成后发送通知 |
| 同步模式 | 复制文件 / 创建软链接 |
| 目录映射 | 每行一对，格式 `源目录:目的目录`，支持子路径 |
| 同步文件后缀 | 逗号分隔，仅同步这些后缀的文件 |

### 文件过滤

| 配置项 | 说明 |
|--------|------|
| 删除附属文件 | 源文件删除时一并清理同名的附属文件 |
| 附属文件后缀 | 逗号分隔，如 `.jpg, .nfo, .png, .srt` |

## 使用示例

```
目录映射：
/media/source/movies:/media/target/movies
/media/source/tvshows:/media/target/tvshows

同步文件后缀：
.strm, .mkv, .mp4, .avi, .ts, .iso
```

源目录 `/media/source/movies` 下有 `/电影/国产电影/xx.mp4`，目的目录 `/media/target/movies` 下自动同步为 `/电影/国产电影/xx.mp4`。

## 触发方式

- **实时监控**：启用插件后自动启动
- **立即全量同步**：配置页开关
- **命令**：`/filesync`
- **API**：`GET /api/v1/plugin/FileSync/full_sync?apikey=xxx`
